# Code of Conduct

Falconia adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, be kind, assume good faith, and focus on what is best
for the community. Harassment, personal attacks and discriminatory language are
not tolerated, in issues, pull requests, discussions or anywhere else the
project lives.

## Reporting

Report unacceptable behavior privately to the maintainers by opening a
[private security advisory](https://github.com/clackes/falconia/security/advisories/new)
marked "Code of conduct", or by contacting a maintainer directly. Reports are
handled confidentially, and maintainers will act according to the enforcement
guidelines of the Contributor Covenant.
